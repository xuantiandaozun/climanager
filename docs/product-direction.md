# 产品方向

## 一句话

CLI Manager 是一个本地优先的 AI CLI 编码工具工作区管理器，帮助程序员把项目、终端工具和历史会话关联起来。

## 当前优先级

1. 自己愿意每天用
2. GitHub 开源发布
3. 支持 Windows 桌面体验
4. 后续有人关注再增强跨平台和商店分发

## 不做什么

- 不做 IDE
- 不做云同步平台
- 不做终端模拟器内核
- 不强行统一所有 AI 工具的内部会话格式

## MVP

1. 添加工作区目录
2. 配置 CLI 工具命令
3. 在指定工作区中启动指定工具
4. 记录启动历史
5. 索引各工具的会话历史文件
6. 支持按工作区、工具、时间检索

## 已完成

1. Tauri + Vue 桌面应用骨架
2. SQLite 本地数据库
3. 工作区添加、删除、列表
4. 内置工具种子数据：`opencode`、`codex`、`claude code`
5. PATH 工具检测
6. Windows PowerShell 终端启动
7. 启动历史记录
8. 代理配置持久化
9. 启动终端时注入 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`
10. 会话历史文件扫描和 SQLite 索引

## 会话索引设计

第一版不强行解析 `opencode`、`codex`、`claude code` 的私有历史格式，而是做保守索引：

- 扫描常见本地历史目录
- 只读取 2MB 以内的文本类文件
- 如果内容包含工作区路径、Windows 风格路径或工作区名称，则建立关联
- 保存文件路径、更新时间、匹配方式
- 不修改原始历史文件

后续如果确定某个工具的格式稳定，再为该工具增加专用解析器。

## 代理设计

代理配置先按简单实用处理：

- 默认 host：`127.0.0.1`
- 默认 port：`7890`
- 代理 URL：`http://host:port`
- 启动 CLI 工具时写入当前终端进程环境变量

这不会修改系统代理，也不会污染全局环境变量。

## 后续可扩展方向

- SQLite 本地数据库
- 自定义终端配置
- 会话摘要和收藏
- 工具安装检测
- GitHub Release 自动构建
- MSIX 打包和商店上架
